# Cidade BônusHora — Atlas Global v0.1

MVP documental bilíngue para `bonushora-site`, React + Vite + React Router.

## Conteúdo
- `/pt` e `/en`: página inicial e vídeo HeyGen original preservado;
- Brasil/Brazil: mapa de estados com marcador de Salvador;
- Mundo/World: atlas de países com Brasil destacado;
- Cidade/City: mapa urbano esquemático clicável;
- Experimentos/Experiments: E01–E06 como **planejados**;
- Outros mundos/Other worlds: cenário hipotético claramente rotulado;
- Histórico/History: eventos documentais iniciais, sem fingir execução científica.

## Condições

Os mapas recuperam GeoJSON externo em tempo de execução. Isso exige Internet no navegador, autorização de uso adequada e disponibilidade da fonte. Antes da produção pública, recomenda-se hospedar cópias locais verificadas/licenciadas de GeoJSON para estabilidade. A linha do tempo inicial é **documental**, não uma série de experimentos executados. O vídeo é material prévio com aviso de escopo.

O script aplica mudanças somente a uma branch local recém-criada, a partir do SHA de baseline verificado `b15d41c6b528d95a3277aa208f0fac3f72c83522`. Sem commit, push ou publicação automática.
